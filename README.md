# Argent Bank

Projet 10 OpenClassrooms : front-end de l'application Argent Bank (phase 1, authentification des utilisateurs).

## Installation

Le back-end doit être lancé en premier : https://github.com/OpenClassrooms-Student-Center/Project-10-Bank-API (il faut Node et MongoDB).

Dans le dossier du back-end :

```
npm install
npm run dev:server
npm run populate-db
```

Puis dans le dossier `argent-bank` :

```
npm install
npm run dev
```

L'application tourne sur http://localhost:5173 et l'API sur http://localhost:3001 (documentation sur http://localhost:3001/api-docs).
